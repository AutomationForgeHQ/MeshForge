# Contributing

This repository is the **published source** of `MeshForge`, part of the
[Automation Forge](https://github.com/AutomationForgeHQ) suite for Unreal Engine.
Its contents are replaced by each release, so a pull request opened here cannot be
merged and would be overwritten by the next one.

**Issues and discussion are welcome here** — that is what this repository is for,
alongside reading the source.

To propose a change, open an issue describing it. Development happens in a monorepo
where this plugin is built and tested against the rest of the suite; an accepted
change is made there and arrives in the next release, with attribution.
